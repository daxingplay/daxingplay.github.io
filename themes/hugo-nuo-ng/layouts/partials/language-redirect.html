{{- /* First-visit language detection. Runs inline in , before anything paints, so a redirect never shows a flash of the wrong language. Rules, in order: 1. An explicit choice (saved by the language switcher) always wins. 2. Otherwise the browser's Accept-Language preference order decides. 3. Either way we only move if this exact page really exists in that language — no bouncing a reader to a home page they didn't ask for. Because the choice lives in localStorage, this is invisible to the CDN and to crawlers: every URL still serves one fixed language. */ -}} {{- partial "language-links.html" . -}} {{- $targets := dict -}} {{- range ($.Scratch.Get "languageLinks") -}} {{- if .translated -}} {{- $targets = merge $targets (dict .lang .url) -}} {{- end -}} {{- end -}}
